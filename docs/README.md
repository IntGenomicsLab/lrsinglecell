# IntGenomicsLab/lrsinglecell: Documentation

The IntGenomicsLab/lrsinglecell documentation is split into the following pages:

- [Tutorial](tutorial.md)
  - A step-by-step walkthrough: install, run the test data, write a samplesheet, run on your own data and load the results in R.
- [Usage](usage.md)
  - An overview of how the pipeline works, how to run it and a description of all of the different command-line flags.
- [Output](output.md)
  - An overview of the different results produced by the pipeline and how to interpret them.
